Electronics Circuit by Suriya PTC
=================================
เว็บนี้เป็นไฟล์เดียว (index.html) ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล
นำไปวางบนโฮสติ้งเว็บแบบ static ที่ไหนก็ได้ ฟรี
=================================
วิธีที่ 1 — Netlify Drop (ง่ายที่สุด ~1 นาที)
  1. เปิด https://app.netlify.com/drop
  2. ลากโฟลเดอร์นี้ (ที่มี index.html) ไปวาง
  3. ได้ลิงก์ เช่น https://xxxx.netlify.app ใช้งานได้ทันที
  4. สมัครบัญชีฟรีเพื่อเก็บเว็บไว้ถาวรและเปลี่ยนชื่อเป็น เช่น circuit-bench-pnsk.netlify.app
=================================
วิธีที่ 2 — GitHub Pages (ฟรี เหมาะถ้าจะอัปเดตบ่อย)
  1. สมัคร/เข้าสู่ระบบ https://github.com แล้วสร้าง repository ใหม่ ตั้งเป็น Public
  2. กด "uploading an existing file" แล้วอัปโหลด index.html → Commit
  3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
  4. รอ 1–2 นาที จะได้ลิงก์ https://<ชื่อผู้ใช้>.github.io/<ชื่อrepo>/
  อัปเดตเว็บ: อัปโหลด index.html ทับไฟล์เดิม
=================================
วิธีที่ 3 — โฮสติ้งของวิทยาลัย
  อัปโหลด index.html ไปไว้ในโฟลเดอร์ใดก็ได้ของเว็บวิทยาลัย (เช่น /circuit/)
  แล้วเปิด https://<เว็บวิทยาลัย>/circuit/
=================================
หมายเหตุ
  - ข้อมูลตารางใบงานและโหมดที่เลือก บันทึกในเบราว์เซอร์ของแต่ละคน (ไม่แชร์กัน)
  - ฟอนต์โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยในเครื่องแทน ใช้งานได้ตามปกติ
  - เปิดไฟล์ index.html ในเครื่องโดยตรง (ดับเบิลคลิก) ก็ใช้งานได้ ไม่ต้องต่อเน็ต
